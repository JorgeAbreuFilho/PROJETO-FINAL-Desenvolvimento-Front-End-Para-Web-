# Mochileiro Fácil

Guia de viagem pelo Brasil feito para mochileiros. O site mostra os pontos turísticos, a comida típica e a melhor época para visitar as cidades mais procuradas do país, de um jeito divertido e informal.

Projeto final da disciplina de Desenvolvimento Front-End para Web, feito apenas com HTML e CSS.

## Tema e objetivo

Quem viaja de mochila costuma gastar tempo pesquisando em vários sites antes de decidir pra onde ir. O Mochileiro Fácil junta o básico de cada destino em um só lugar, com linguagem leve e direta, para ajudar a planejar a viagem sem complicação.

## Público-alvo

Mochileiros e viajantes que querem conhecer as cidades mais visitadas do Brasil e buscam informações rápidas e fáceis de entender.

## Funcionalidades

- Menu lateral para navegar entre as cidades
- Uma página para cada destino
- Pontos turísticos de cada cidade
- Botão que abre e fecha a comida típica e a melhor época
- Efeito de mudança de cor ao passar o mouse nos links e no botão
- Destaque em negrito no link da página que está aberta

## Tecnologias usadas

- **HTML5:** estrutura das páginas, com as tags `header`, `nav`, `main`, `footer` e `details`
- **CSS3:** cores, layout com `flex` e efeitos com `:hover`

## Como rodar o projeto

1. Baixe ou clone o repositório

```bash
git clone https://github.com/JorgeAbreuFilho/PROJETO-FINAL-Desenvolvimento-Front-End-Para-Web-.git
```

2. Abra a pasta do projeto
3. Dê dois cliques no `index.html` para abrir no navegador
4. Use o menu lateral para navegar entre as cidades

Não precisa instalar nada.
